# PHASE 12 — Demo & Limited Live

## Objective

รัน demo trading ต่อเนื่อง แล้วเปิด live แบบจำกัด

## Pre-Requisites

```
ก่อนเริ่ม Phase 12:

1. Backtests reproducible
2. Paper stable
3. Risk Engine validated
4. Kill Switch tested
5. No duplicate execution
6. MT5 reconnect tested
```

## Demo Trading Gate

```
Backtests reproducible ✓
Paper stable ✓
Risk Engine validated ✓
Kill Switch tested ✓
No duplicate execution ✓
MT5 reconnect tested ✓
→ ALLOW DEMO
```

## Safety Rules

```
1. LIVE mode ต้อง LOCKED เป็น default
2. เปิดได้เฉพาะ manual approval
3. Limited: min position, low risk, limited symbols
4. Kill Switch ทำงานตลอด
5. Manual emergency process documented
```
